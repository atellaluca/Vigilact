# Project & maintainer

![Vigilact icon](assets/vigilact-logo.svg)

**Vigilact** is an independent, Apache-2.0 open-source experiment in operational contracts and observable evidence. It is not a notification service, a ratified standard or a production-grade monitoring platform. The protocol is designed to be implementation-neutral.

## Where to ask questions

For reproducible bugs, feature discussions or technical questions, prefer the [GitHub issue tracker](https://github.com/atellaluca/vigilact/issues). For collaboration enquiries, use the contact details above. **Do not disclose exploitable vulnerabilities in public issues:** follow the repository [security policy](https://github.com/atellaluca/vigilact/blob/main/SECURITY.md) instead.

Project affiliation with the maintainer does not make independently developed compatible implementations official. See [Compatibility](reference/compatibility.md) and [Conformance](reference/conformance.md).
