# Support

**Vigilact is experimental and is not a production-supported service.**

- Search existing GitHub issues before reporting a reproducible bug.
- Use the bug report template for errors and the protocol proposal template for
  changes to the wire format or semantics.
- GitHub Discussions can be used for help and architecture questions once the
  repository owner enables Discussions.
- For potential vulnerabilities, use private GitHub Security Advisories; never
  paste exploitation details, credentials or private operational data into an issue.

Include the implementation version, Python version, expected behavior, actual
behavior, a minimal example with synthetic data, and relevant sanitized logs.
Maintainer response and release times are best effort; no SLA is offered.
